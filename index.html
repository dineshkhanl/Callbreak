Flas

1. Triple / Thiral: AAA, KKK, QQQ
2. Dabrun: same-suit sequence
3. Run: sequence in any suits
4. Flas: same suit, not a run
5. Jut / Pair: two cards of the same rank, for example A-A-2 = A Jut, K-K-5 = K Jut. A Jut is highest and 2 Jut is lowest. If two players have the same Jut, compare the third card: A-A-7 beats A-A-4.
6. Top: compare highest cards
